# Happy Diwali — painted greeting video

A 21-second vertical (1080×1920, 30 fps) Diwali greeting. Shri Ram, Sita, Lakshman and
Hanuman are painted stroke by stroke with [p5.brush](https://github.com/acamposuribe/p5.brush)
(standalone build) in front of a night-time Ayodhya. Then diyas light up, fireworks go off,
and the title "जय श्री राम · Happy Diwali" appears. The voiceover comes from Kokoro TTS, and
all music and sound effects are synthesized in code.

**Finished video:** `out/Happy_Diwali_Jai_Shri_Ram.mp4` (poster: `out/poster.jpg`).

## Files

| Path | What it is |
| --- | --- |
| `scene.js` | The painting: every brush stroke and its time, plus the light layer (flames, halo glow, stars, fireworks, title). |
| `index.html`, `brush.js` | Page that runs the scene; `brush.js` is p5.brush's `dist/brush.js` (MIT). |
| `voice/lines.json` | Voice script and the start time of each line. |
| `tools/kokoro_lines.py` | Renders each line with Kokoro, with phonetic fixes for Ram, Shri, Sita, Lakshman, Hanuman, Ayodhya, diyas. |
| `tools/render.cjs` | Renders the frames in headless Chromium and encodes `out/diwali_silent.mp4`. |
| `tools/make_audio.py` | Synthesizes the music and sound effects, places the voice, mixes (voice −16 LUFS, music ducked, total −14 LUFS). |
| `tools/listen_check.py` | Whisper speech-recognition check of the final mix against the script. |

## Rebuild

Needs Node with Playwright/Chromium, ffmpeg, and a Python venv with `kokoro-onnx soundfile numpy scipy pyloudnorm faster-whisper`.
The Kokoro model files `kokoro-v1.0.onnx` and `voices-v1.0.bin` come from the
[kokoro-onnx releases](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0);
`tools/kokoro_lines.py` expects them in `/root/kokoro/`.

```bash
python -I tools/kokoro_lines.py . --voice af_heart
node tools/render.cjs
python -I tools/make_audio.py .
ffmpeg -y -i out/diwali_silent.mp4 -i audio/final_mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest out/Happy_Diwali_Jai_Shri_Ram.mp4
python -I tools/listen_check.py .
```

Preview a few frames without a full render: `node tools/render.cjs --preview 6,10,20.9` (writes `frames/preview_NN.jpg`).
